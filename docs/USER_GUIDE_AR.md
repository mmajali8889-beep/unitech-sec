# دليل المستخدم (العربية)

> ملاحظة: مصادر V2 (VibeSec وBEKO وغيرها) لم تكن متاحة أثناء البناء، لذا لم يتم دمجها بعد — راجع `ENGINE_AUDIT.md`.

1. **التشغيل**: شغّل `scripts/start_local.py` (أو `start.ps1`). سيُطبع كلمة مرور مؤقتة للمدير؛ افتح `http://127.0.0.1:8787` وغيّر كلمة المرور فوراً.
2. **الوكيل المحلي**: يعمل الوكيل مع المشغّل. صفحة *صحة النظام* يجب أن تُظهره **متصلاً** مع المجلدات المعتمدة. لا يمكن تصفح أو فحص أي مجلد خارجها.
3. **تسجيل مشروع**: *المشاريع ← اكتشاف* أو *تسجيل* (اختر من متصفح المجلدات المعتمدة). المسارات الخارجة عن المجلدات المعتمدة تُرفض.
4. **الفحص**: *مركز الفحص* ← المشروع ← المحركات (غير المتاحة معطّلة) ← *ابدأ الفحص*؛ أو *فحص الملفات والمجلدات* لفحص مباشر.
5. **المتابعة**: *مراقبة الفحص المباشر* تعرض التقدم والأحداث الحقيقية؛ زر *إلغاء* يوقف عملية الفحص.
   الحالات: في الانتظار، قيد التنفيذ، مكتمل، **مكتمل جزئياً** (فشل أحد المحركات)، فشل، ملغى.
6. **المراجعة**: صفحات الشيفرة والأسرار والاعتمادات وDocker وإدارة الثغرات تُرشّح النتائج بالخطورة والحالة والتحقق والمشروع. افتح أي نتيجة لرؤية المعالجة، وسجّل الفرز (يبقى بعد إعادة الفحص).
7. **BEKO**: اختياري؛ يرسل فقط بيانات وصفية مُجمّعة للقواعد (مع معاينة). الناتج **غير موثّق** حتى يضع مراجع بشري علامة المراجعة. عند توقف Ollama تبقى نتائج الفحص كاملة.
8. **التقارير**: *مركز التقارير* ← JSON / HTML / SARIF / PDF ← تنزيل. *سجل الفحوصات* يقارن الفحص بالسابق (جديدة / مُصلَحة / فرق الخطر).
9. **الجدولة**: فحوصات يومية أو دورية لكل مشروع، وإشعارات Webhook اختيارية (عناوين محلية/خاصة فقط) من *الإعدادات*.
10. **الإدارة**: *المستخدمون والصلاحيات* (مدير، محلل، مشاهد، مدقق)، *سجلات التدقيق* (التحقق من السلسلة)، *محركات الأمن* (تفعيل/تعطيل).

الأدوار: **المدير** كل شيء · **المحلل** تسجيل/فحص/فرز/تقارير/جدولة/BEKO · **المشاهد** قراءة فقط · **المدقق** قراءة + سجلات التدقيق.

## الاسترجاع والتراجع
كل ما يكتبه V3 داخل مجلد `data/` فقط. للتراجع: أوقف التشغيل واحذف مجلد V3؛ V2 وPostgreSQL لا يتأثران. التفاصيل في `ROLLBACK_RECOVERY.md`.
